# 이미지와 콘텐츠 기록

## 기존 사이트 이미지

`assets/environment.png`, `world.png`, `object.png`, `space.png`는 기존 사이트에서 사용하던 AI 생성 디자인 샘플입니다. 실제 사용자 프로젝트의 제작 성과를 증명하는 화면이 아닙니다. 사이트에도 AI 샘플 표시가 유지되어 있습니다.

`assets/damascus-original.png`와 `damascus-original-prompt.txt`는 앞선 배경 제작 결과와 프롬프트 기록입니다. 현재 배경은 `damascus.js`가 그리는 도트 패턴이며 이 PNG를 배경으로 불러오지 않습니다. 기존 작업 보관을 위해 함께 담았습니다.

## 사용자 콘텐츠

소개·수상·경험 내용과 외부 링크는 기존 사이트 소스를 유지했습니다. 수상 표기는 기존 페이지의 ‘우수작’ 표현을 유지했으며, 제출 전에 상장 기준 확인이 필요하다는 기존 안내도 남아 있습니다.

OutBreak 관련 메모는 제공된 기획서와 Canva 화면을 바탕으로 작성했습니다. 기획서 원본, Canva 원본 이미지, 영상은 포함하지 않았습니다.

## 패키지 범위

기존 정적 사이트 파일 15개를 내용 변경 없이 복사하고, README와 문서·Git 설정 파일을 추가했습니다. 로컬 Git 이력, ChatGPT Sites의 연결 설정, 인증 정보 및 임시 브라우저 데이터는 업로드 패키지에 포함하지 않았습니다.
