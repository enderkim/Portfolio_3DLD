# ENDERKIM 포트폴리오

김태연의 3D 아트 · 레벨디자인 포트폴리오 웹사이트입니다. 2026년 9월 18일에 기존 사이트의 로컬 소스를 GitHub 업로드용으로 정리한 버전입니다.

## 현재 포함된 작업

- 메인 → 작업 → 경험 → 소개 구성
- 이미지 중심의 프로젝트 4개와 클릭해서 여는 상세 작성 양식
- 화면 크기에 맞춘 섹션 배치와 스크롤 페이드 효과
- 마우스 휠로 섹션 이동, 긴 내용과 상세창의 개별 스크롤
- 코드로 그리는 도트 다마스커스 배경과 대각선 애니메이션
- 배경 모션 켜기·끄기, 기기의 모션 감소 설정 대응
- 수상·전시·부스 운영 경험과 소개

**OutBreak 상세 양식 개편은 아직 사이트에 적용하지 않았습니다.** 이번 작업에서 확인한 기획서 내용, Canva 디자인과 이후 구현할 구조는 [OutBreak 작업 메모](docs/OUTBREAK-PLAN.md)에 정리했습니다. 현재 프로젝트 이미지는 화면에 표시된 대로 AI 샘플입니다.

## 내 컴퓨터에서 보기

압축을 풀고 `index.html`을 브라우저로 열면 됩니다. 별도 설치나 빌드가 없는 HTML · CSS · JavaScript 사이트입니다. `assets` 폴더와 나머지 파일은 같은 구조로 유지하세요.

로컬 서버가 필요하고 Python이 설치되어 있다면 이 폴더에서 다음 명령을 실행합니다.

```sh
python -m http.server 8080 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8080`을 엽니다. 종료는 터미널에서 `Ctrl+C`입니다.

## GitHub에 업로드하기

1. GitHub에서 사용할 저장소를 엽니다.
2. **Add file → Upload files**를 선택합니다.
3. ZIP 자체가 아니라 압축을 푼 이 폴더의 **내용물**을 올립니다. `index.html`, `assets/`, `docs/`가 저장소 최상위에 놓이도록 합니다.
4. 변경 설명을 적고 GitHub 화면 안내에 따라 저장합니다.

[GitHub 공식 파일 업로드 안내](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository)

이 패키지는 업로드할 파일만 준비한 것입니다. GitHub 저장소 생성, 업로드, 사이트 공개 배포는 수행하지 않았습니다. 기존 ChatGPT 사이트의 로그인 제한은 소스 파일에 포함되는 기능이 아닙니다.

## 수정할 파일

| 파일 | 용도 |
| --- | --- |
| `index.html` | 메인 구성, 경험, 소개 |
| `content.js` | 프로젝트 이름·설명·이미지 경로·담당 역할 |
| `app.js` | 프로젝트 목록과 상세 양식 |
| `style.css` | 기본 레이아웃과 반응형 스타일 |
| `damascus.css` | 어두운 색상과 유리 느낌 패널 |
| `damascus.js` | 도트 배경과 모션 제어 |
| `motion.js` | 섹션 페이드 효과 |
| `paging.js` | 휠 입력에 따른 섹션 이동 |
| `viewport.js` | 화면 높이 대응 |
| `assets/` | 기존 이미지와 배경 제작 기록 |

이미지 및 콘텐츠의 구분은 [ASSETS.md](docs/ASSETS.md)를 참고하세요. 외부 라이브러리와 패키지 설치가 필요하지 않습니다. 저장소 전체에 임의의 오픈소스 라이선스를 부여하지 않았습니다.
